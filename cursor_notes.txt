## Timelapse -> TIF converter (2026-06-16)
- Tool: `tools/timelapse/convert_timelapse.py` (py -3; needs numpy + Pillow, see its requirements.txt). tifffile NOT installed; uses Pillow for TIF (8-bit RGB, LZW).
- Source frames: viewer RawTimelapseRecorder output. `*-u16.bin` = raw 908x192 LE u16 payload, NO header (348672 B after 2026-07-29 zero-pitch bake; older recordings were 908x160 = 290560 B). `.irpv` = same payload + 98 B header/meta (HeaderBytes 22 + MetaV2 72 + 4 trailer). Converter reads the `-u16.bin`.
- Temp math mirrors viewer HikTherm: C = (raw + 0x37C0)/64 - 273.15. raw==0 = no-data (uncovered warp/edge, renders as Jet floor/blue) and is EXCLUDED from range stats.
- Range: per-frame p1/p99 of valid px, then heavy EMA (`--ema-alpha` default 0.05) so min/max drift slowly -> no frame-to-frame flicker. `--min-span` 2.0 C. Linear map -> 256 LUT. HDR/local tone map is a future swap in `map_to_display()`.
- Jet LUT replicates ThermalColormap.Jet exactly. 8-bit RGB out.
- Output: `--output` (default `<input>/converted`), names `CONVERTED_NNNNNN.tif` starting `--start-index` 100000, +1 per output. `--skip` 100 (every Nth frame, fs[::skip]). Writes `convert_log.csv` (per-frame percentiles + locked window).
- Test data: `C:\Users\ericj\OneDrive\Documents\thermal-test\timelapse-20260615-211625` (29338 frames; skip=100 -> 294 TIFs). Scene ~ -1..28 C. Verified render: cool sky blue, warm terrain red. ~26 fps.
- Run full: `py -3 tools/timelapse/convert_timelapse.py` (uses default input/output). `--limit N` for quick tests.
